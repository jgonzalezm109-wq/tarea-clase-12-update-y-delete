Sistema de Control de Gastos 

Aplicación de consola desarrollada en C# (.NET 8) correspondiente a la tarea de la **Clase 12** del curso **008 Algoritmos** de la Universidad Mariano Gálvez de Guatemala (UMG), Centro Universitario de Chiquimulilla.


## Instrucciones para Ejecutar
1. Abre el proyecto en **Visual Studio Community 2026**.
2. Asegúrate de tener seleccionado el archivo `Program.cs` como punto de entrada.
3. Presiona **`F5`** (con depuración) o **`Ctrl + F5`** (sin depuración).
